# Файлы для итогового задания
`tests` содержит тесты для проверки API, которое должно быть реализовано в веб-сервере.
`web` содержит файлы фронтенда.
в директории `pkg` лежат поддиректории:
`server` содержит файлы для запуска сервера.
`api` содержит файлы с обработчиками запросов и файл с их регистацией.
`db` содержит файл создания базы данных и файлы с описанием функций.

# Задания со звездочкой
Выполнена сборка docker image, 
приложение назвается todo-list

# Инструкция по запуску кода локально
Для запуска локально использовать - http://localhost:7540/
Для запуска image порт - 7540:7540

# Инструкция по запуску тестов 
В tests/settings.go указать параметры:
var Port = 7540
var DBFile = "../scheduler.db"
var FullNextDate = false
var Search = false
var Token = ``

# Инструкция по сборке и запуску проекта через docker
Из корневой директории собрать образ:
docker build --tag todo-list .
Из корневой директории запустить контейнер (порт-переменная окружения):
docker run -p 7450:7450 -e PORT=7450 todo-list
Перейти на http://localhost:7540/
